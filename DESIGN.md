# Sikar Drop — Design System & Visual Specification

## 1. Aesthetic Identity
- **Reference Image Match**: Modeled directly on client's provided reference layout (`media_1791644538172.jpg`).
- **Color Palette**: Glacier Blue (`#0369A1`), Deep Corporate Navy (`#0F3D64`), Dark Midnight (`#0B192C`), Pure Studio White (`#FFFFFF`).
- **Zero Emojis**: Complete ban on emojis. All UI icons are crisp, high-resolution SVG vector paths.
- **Product Presentation**: Clean studio packshots isolated on pure white backgrounds, giving an ultra-modern 2026 beverage catalog look.

## 2. Core Business Boundaries
- **Strict Policy**: 100% Factory-Sealed Bottles, Multi-Pack Petis & Crates Only.
- **Explicit Rule**: **Hum 20L Water Jar (Camper) Supply Nahi Karte**.
- **Delivery Corridors**: Piprali Road Coaching Hub, Nawalgarh Road, Station Road, Krishi Mandi, Fatehpur Road, Rani Sati Road.

## 3. Key Functional Flows
- **Cart & Wishlist**: Real-time reactive state with drawer tray.
- **Login Authentication Gate**: Mandatory Mobile + OTP verification before order confirmation.
- **WhatsApp Dispatch**: Automated order routing to Sikar Central Depot.
- **Order Tracking**: Order ID lookup with 4-stage vehicle dispatch timeline.
- **Wholesale Bulk Calculator**: Interactive peti volume calculator with real-time wholesale discounts.
